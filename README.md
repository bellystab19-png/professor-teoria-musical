# Professor de Teoria Musical

Aplicativo educacional web, autocontido, para estudo de teoria musical.

## Acessar

Após ativar o GitHub Pages neste repositório, o aplicativo ficará disponível em:

**https://bellystab19-png.github.io/professor-teoria-musical/**

## Conteúdo

1. O que é Música
2. Propriedades do Som
3. Elementos Musicais
4. Notação Musical
5. Leitura Rítmica
6. Melodia e Solfejo
7. Intervalos
8. Escalas e Modos
9. Acordes e Harmonia
10. Forma e Textura
11. Exercícios Integrados
12. Glossário
13. Teoria do Ethos

## Como usar

1. Abra o arquivo `index.html` no navegador, ou acesse o endereço do GitHub Pages.
2. Navegue pelos módulos no menu lateral.
3. Use **Imprimir** para imprimir ou salvar como PDF pelo navegador.

## Publicação (GitHub Pages)

1. Abra o repositório no GitHub.
2. Vá em **Settings → Pages**.
3. Em **Source**, escolha **GitHub Actions** (recomendado) ou **Deploy from a branch** (`main` / `/` raiz).
4. Aguarde alguns minutos e acesse o endereço acima.
