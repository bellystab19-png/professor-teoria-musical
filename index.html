Professor de Teoria Musical

Repositório publicado. Para colocar o aplicativo completo no ar:

  1. Abra o repositório no GitHub.
  2. Faça o upload do arquivo index.html completo (substitua este arquivo).
  3. Em Settings → Pages, defina a origem como GitHub Actions.
  4. Aguarde o workflow e acesse:
    https://bellystab19-png.github.io/professor-teoria-musical/

O arquivo completo do aplicativo está no chat e pode ser baixado para substituição neste repositório.
